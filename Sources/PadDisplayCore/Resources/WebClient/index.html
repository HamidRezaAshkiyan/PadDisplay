Unlock 60fps H.264 Mode

iPad Safari requires HTTPS for hardware WebCodecs 60fps streaming. Do this quick one-time setup:

  1. Tap Install Local CA Profile and tap Allow.
  2. Open iPad Settings → General → VPN & Device Management → tap PadDisplay Local HTTPS → Install.
  3. Go to Settings → General → About → Certificate Trust Settings and enable full trust for PadDisplay Local CA.
  4. Return here and open 60fps HTTPS mode:
